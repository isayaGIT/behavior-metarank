# Protocol

This repository is intended to evolve into an open umbrella review / meta-research project.

## Principle: discovery without a closed candidate list

Mechanisms are not limited to a predefined ontology. New mechanisms can enter the evidence base when discovered through systematic searches, citation chaining, existing reviews, or contributor proposals. Inclusion is determined by explicit construct and evidence criteria, not by membership in an initial keyword list.

## Evidence must be stratified

Do not pool these layers into one effect estimate without an explicit model:

- association
- prospective
- causal
- mediation

## Minimum extraction rules

For every synthesized estimate, record:

- construct definition
- behavior domain
- study design
- effect metric
- effect value
- uncertainty when available
- number of effects/studies (k) when available
- sample size (n) when available
- source IDs
- caveats

## Planned methodological work

Before publication-quality ranking:

1. preregister search and inclusion rules;
2. define duplicate/overlap handling for meta-analyses sharing primary studies;
3. define effect-size harmonization rules;
4. assess review quality / risk of bias;
5. define ranking dimensions;
6. perform sensitivity analyses for any composite score.
