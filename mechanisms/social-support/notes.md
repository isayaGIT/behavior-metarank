# Social support

## Cluster boundary
Social support is an interpersonal resource, not a norm. Norms describe perceived standards or prevalence of behavior; support provides practical, informational, emotional, or tangible assistance.

Peer support is currently treated as a subtype. It should split into a separate folder only if a sufficiently broad quantitative literature yields a distinct estimand.

## Domain caution
The current causal estimate is specific to antiretroviral therapy adherence and is not a universal social-support effect.
